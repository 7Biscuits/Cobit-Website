# Assets

Static resources for the CoBit 3D City & Website experience.

- Fonts: Loaded via Google Fonts CDN (`Space Grotesk`, `Inter`).
- Icons: Rendered via optimized, inline scalable vector graphics (`SVG`) in the DOM and modal footer.
- 3D Textures: Generated procedurally at runtime using HTML5 Canvas (`js/utils/textures.js`) for crisp resolution and high performance without network asset latency.
